# Vappie dashboard redesign

Deze versie behoudt de bestaande Vappie-functionaliteit, localStorage-key (`vappie-data-v2`), Supabase-configuratie, login, directe synchronisatie, 2-minuten pull, Excel-import en rapport-export.

Visuele wijzigingen:
- Vappie-logo overal aangepast van V naar Z.
- Desktop: vaste zwarte zijbalk met gele actieve navigatie.
- Bovenbalk: synchronisatiestatus, festivaljaar en ingelogde gebruiker.
- Lichtere, rustigere kaarten, filters en tabellen.
- Responsive mobiele navigatie via uitschuifmenu.
- Mobiele login blijft compact.

Deploy: upload alle bestanden uit deze map over de bestaande bestanden in GitHub. Vercel kan daarna automatisch deployen.
